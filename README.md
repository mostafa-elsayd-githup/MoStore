## 🌟 About The Project

This is a modern, high-performance **MoStore E-Commerce Single Page Application (SPA)** designed for seamless product discovery and shopping. Built with a strong focus on clean architecture, performance optimization, and localized Arabic user experience (RTL layout).

## ✨ Key Features

- **⚡ High-Performance Search:** Implements real-time product search with **Debouncing (400ms)** and **Supabase `ilike` pattern matching** for flexible Arabic product discovery.
- **🔄 Efficient State & Data Management:** Powered by **TanStack Query v5** for robust server-state caching, background refetching, and automatic request optimization.
- **🌓 Dynamic Theme Switching:** Fully customized Light and Dark mode implemented cleanly via **CSS Custom Properties (Variables)**.
- **🎨 Smooth UI Animations:** Integrated with **Framer Motion** for fluid page transitions and engaging interactive components.
- **🛒 Interactive Shopping Experience:** Real-time cart updates, wishlist handling, and optimized responsive UI across all screen breakpoints.
- **🔒 Secure Backend Integration:** Seamlessly connected with **Supabase** for secure product data retrieval and robust database queries.


## 🛠️ Tech Stack

- **Frontend:** React, Vite, TypeScript/JavaScript
- **Styling & UI Components:** Tailwind CSS, CSS Custom Properties, Swiper (for interactive carousels)
- **State & Data Management:** TanStack Query (React Query), Zustand, Axios
- **Form Handling & Validation:** React Hook Form, Zod
- **Animations:** Framer Motion
- **Backend & Database:** Supabase (PostgREST)
- **Icons:** Lucide React
